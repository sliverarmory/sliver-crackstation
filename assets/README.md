# Assets

This directory contains static assets, mostly generated by `make assets` but a few others are just committed directly to the git repo.

Hashcat is pinned to [sliverarmory/hashcat v8.0.0-armory.2](https://github.com/sliverarmory/hashcat/releases/tag/v8.0.0-armory.2),
built from source commit `d745d3074dd296fdc1e91c9e48dee8a317d3c2d8`.
Run `make assets` to download the Windows/amd64, Linux/amd64, and Darwin/arm64
archives. The downloader verifies the release manifest and each archive against
the SHA-256 checksums pinned in `util/assets/main.go`. Generated ZIP files are
ignored by Git; `go test ./util/assets` checks their checksums and build provenance.
